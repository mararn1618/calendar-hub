# Daymark calendar reference

Both the main checkout and the calendar worktree pointed to `89e8357d7cc5b8aadfbd01562a4caaad2db9e72d` on 18 November 2026. The worktree was clean. Main had local instruction and attachment changes outside the calendar code.

| Area | What Calendar Hub can learn from Daymark | Evidence |
| --- | --- | --- |
| Calendar layout | Day and Week combine timed blocks with a strip for items without a time. The grid handles overlapping items, moving a block and resizing either end. | [Calendar component](../../context/daymark-worktree/src/ui/Calendar.tsx), [planning behavior](../../context/daymark-worktree/docs/implementation/calendar-planning.md) |
| Date ranges and scrolling | Daymark's Week displays seven days starting at the selected date. Its arrows move seven days at a time. The grid scrolls through overflowing columns, but has a fixed day count for each timeline view. A calendar-aligned week and a selectable Next X Days range need their own behavior. | [Date range selection](../../context/daymark-worktree/src/ui/Calendar.tsx), [navigation tests](../../context/daymark-worktree/tests/calendar-view.test.ts), [scroll layout](../../context/daymark-worktree/src/ui/styles.css) |
| Tasks on the grid | Dragging a Daymark task from the strip assigns a time. Dragging it back clears the planned time and keeps its deadline. Completing it updates the Daymark task. Calendar Hub needs these gestures to affect the original TickTick task. | [Drag-back tests](../../context/daymark-worktree/tests/calendar-unplan.test.ts), [worktree UI evidence](../../context/daymark-worktree/.tools/calendar-header-compact/ui-verification.json) |
| TickTick connection | The desktop client imports a snapshot or creates copies in a new TickTick list. The importer converts dated tasks to Daymark's model. Inbox coverage is uncertain, and the conversion drops some all-day and single-time detail from the visible calendar. | [Desktop client](../../context/daymark/desktop/ticktick-cloud.ts), [date conversion](../../context/daymark/src/adapters/ticktick.ts), [import coverage](../../context/daymark-docs/implementation/ticktick-import.md) |
| Google Calendar | Selected calendars feed the grid. Eligible events support moving, resizing and deletion. The editor distinguishes a single recurring occurrence and a meeting with attendees. Earlier verification covers live reads. Write tests used simulated Google responses. | [Provider client](../../context/daymark/src/adapters/google-client.ts), [event editor](../../context/daymark-worktree/src/ui/GoogleEventEditor.tsx), [verification](../../context/daymark-docs/implementation/google-calendar.md) |
| Outlook and Exchange | Daymark describes direct Microsoft access and the Mac system calendar as possible routes. Both still require investigation for the BMW account. | [Outlook and Exchange roadmap](../../context/daymark-docs/plan/roadmap.md#phase-3-follow-up-company-outlook-and-exchange-calendars) |

The calendar reads Daymark tasks and selected Google Calendar events. The source has no separate Google Tasks connector. An older Daymark study recorded TickTick sending tasks to Google. A copy could therefore appear alongside an original if both sources are selected.
