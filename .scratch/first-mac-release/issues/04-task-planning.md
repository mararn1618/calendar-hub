Type: grilling
Label: wayfinder:grilling
Status: open
Blocked by: 02

## Question

Which undated, date-only, single-time, overdue, recurring and completed tasks appear on a given day? Walk through creating a task in a chosen list, giving an existing task a time slot, resizing it, taking it back out of that slot and completing it. Decide what must be visible in TickTick after each supported action. Use [Which original TickTick tasks can the app read and change?](02-ticktick-api.md).

Use a multi-day task to decide which day remains when a time slot is removed. For any selected case whose write behavior is undocumented, specify a disposable-account acceptance check covering the same task ID, its other fields, and later occurrences where relevant.
