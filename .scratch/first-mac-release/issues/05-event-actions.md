# How should creating, editing, hiding and deleting an event work?

Type: grilling
Label: wayfinder:grilling
Status: open

## Question

How should I choose the Google calendar for a new event, and what happens when I move, resize, hide or delete one? Use an ordinary appointment, an invitation I received and one occurrence of a series. Decide which actions appear on right-click, how I see the effect on guests before a provider change, and how I find a locally hidden meeting again. Include the read-only BMW fallback.
