# What should I see when a calendar is stale or an edit fails?

Type: grilling
Label: wayfinder:grilling
Status: open

## Question

After waking the Mac, how can I tell whether the workday is current? If I move a Google event or complete a TickTick task while disconnected, or someone changes it before my edit arrives, what should the calendar show and what should it do after reconnection? Set the acceptance behavior for pending, confirmed and failed edits and for one unavailable source.
