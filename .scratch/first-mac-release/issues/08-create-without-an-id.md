# What should I see when a new TickTick task has no confirmed ID?

Type: grilling
Label: wayfinder:grilling
Status: open
Blocked by: 02

## Question

I create a task called “Review slides” at 10 am. TickTick can accept it without returning an ID, or the reply can be lost. Two tasks with that title and time could exist. What should Calendar Hub show while the outcome is unclear, how can I identify the original, and when can I safely retry? Agree on an example that avoids silently creating a second task or linking the wrong one.
